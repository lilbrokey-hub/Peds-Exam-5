# 🎵 Study Music Files

This folder is for storing piano and ambient music files to use with the NURS 2209 Learning Platform.

## How to Add Music Files

### Option 1: Using the Platform (Recommended)
1. Open the learning platform in your browser
2. Click the **🎵 Study Music & Focus Sounds** tab
3. Click the **"Choose Files"** button
4. Select your downloaded piano songs
5. Click **▶️ Play Random Study Music** to start

### Option 2: Adding Files Locally
If you're running this platform locally or on GitHub Pages with files in this folder:
1. Download piano songs from Epidemic Sound (https://www.epidemicsound.com/music/featured/)
2. Save them to this `/music` folder
3. Use the file picker in the platform to select them

## Supported Audio Formats
- MP3 (.mp3) - Recommended
- WAV (.wav)
- M4A (.m4a)
- OGG (.ogg)
- FLAC (.flac)

## Recommended Music Sources
- **Epidemic Sound**: https://www.epidemicsound.com/music/featured/
- **Freepik Piano Music**: https://www.freepik.com/
- **YouTube Audio Library**: https://www.youtube.com/audiolibrary
- **Free Music Archive**: https://freemusicarchive.org/

## Tips for Study Music
- Look for: Relaxing, Ambient, Focus, Inspiring, or Upbeat moods
- Instrumental tracks work best (no distracting lyrics)
- Aim for 3-10 minute songs for good study session lengths
- Download 10-15+ songs for better variety

## Note for GitHub Pages Users
If deploying to GitHub Pages, audio files can be stored in this folder. Make sure to:
1. Keep file sizes reasonable (5-10MB per song max)
2. Use compressed formats like MP3 to reduce repository size
3. Update your .gitignore if you don't want music files tracked in Git

---

**No files are included by default.** Add your own music and they'll be ready to use with the platform!
